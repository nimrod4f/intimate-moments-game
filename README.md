```

בנה אפליקציית web מובייל-first בעברית (RTL מלא) בשם "משחק מקדים" – משחק אינטימיות לזוגות, טלפון אחד לשניים, ללא הרשמה וללא שרת. React + Tailwind, PWA מותקן למסך הבית.



## דיסקרטיות

- שם ה-PWA במסך הבית: "Evening". אייקון: ירח סהר לבן דק על רקע שחור מט, בלי טקסט.

- כותרת הטאב בדפדפן: "Evening".

- שם "משחק מקדים" מופיע רק בתוך האפליקציה.



## עיצוב

- כהה וחמים: רקע #0F0A0D, בורדו עמוק #4A0F24, זהב #C9A45C, ורוד שקוע #D98BA0, טקסט #F5EDE6.

- כפתור "ערב חדש" בתפריט מאפס הכל.



## מסכים



### 1. פתיחה

לוגו טקסטואלי "משחק מקדים", שורה: "ערב של קרבה, מתח ומשחק". צ'קבוקס "שנינו מעל גיל 18" (חובה) וכפתור "מתחילים".



### 2. בונים אווירה – 3 שלבים עם progress dots

שלב א' – "איפה הערב?": 3 כרטיסים – 🛏️ בחדר / 🛋️ בסלון / 🌙 בחוץ.

שלב ב' – "מה שותים?": 🍺 בירה / 🍷 יין / 🍸 קוקטייל.

שלב ג' – "מה השני לובש?" – מנגנון מסירת טלפון:

  1. מסך "בן זוג 1 – כתוב 3 אופציות למה בן/בת הזוג ילבש הערב" – 3 שדות טקסט. כפתור "מוכן – העבר את הטלפון".

  2. מסך ביניים מסך מלא: "העבירו את הטלפון לבן זוג 2" + כפתור "קיבלתי".

  3. בן זוג 2 רואה את 3 האופציות ובוחר אחת.

  4. אותו תהליך הפוך (בן זוג 2 כותב, בן זוג 1 בוחר).

  שמות ניתנים לעריכה: אפשר להזין שמות במקום "בן זוג 1/2".

סיכום אווירה – כרטיס מעוצב: "הערב שלכם: [מיקום] · [שתייה] · [שם 1] לובש/ת: [בחירה] · [שם 2] לובש/ת: [בחירה]". כפתור "למשחקים".



### 3. תפריט משחקים

כרטיס "משחק 1 – הקלפים" (פעיל). כרטיסים "משחק 2", "משחק 3" באפור עם "בקרוב". כפתור קטן "ערב חדש".



### 4. משחק 1 – הקלפים

- 3 כפתורי קטגוריה גדולים אנכית: ❤️ קרבה · 🔥 מתח · 😈 נועז. מתחת לכל אחד מונה "נשארו X מתוך 6".

- לחיצה על קטגוריה → אנימציית ערבוב: ערימת קלפים הפוכים בצבע הקטגוריה מתערבבת מהר 1.5 שניות → קלף אחד מתרומם ומסתובב (flip 3D) ונפתח.

- בחירת קלף: אקראי מתוך הקלפים שטרם נפתחו בקטגוריה. קלף שנפתח לא חוזר.

- כשכל 6 הקלפים בקטגוריה נגמרו: הכפתור הופך לאפור עם "סיימתם את הקטגוריה" – ממשיכים עם השאר. כשכל 18 נגמרו → מסך סיום.

- בקלף: כותרת, טקסט המשימה, ואזור פעולה לפי סוג הקלף. תמיד קיים כפתור "סיימנו" (חזרה לבחירת קטגוריה) וכפתור משני "החלף קלף" – מותר פעם אחת בכל קטגוריה, אחר כך נעלם. קלף שהוחלף חוזר לערימה.



### סוגי קלפים

- text: רק טקסט + "סיימנו".

- timer: כפתור "התחילו" → טיימר מסך מלא: ספרות ענקיות, טבעת התקדמות, השהיה/איפוס, בסיום צליל עדין (פעמון רך) ורטט קצר. אם swap=true: בסיום הטיימר מופיע "מתחלפים 🔄" עם כפתור "התחילו סבב שני" לאותו משך.

- song: כפתור "בחרו שיר ב-Spotify" שפותח https://open.spotify.com בטאב חדש, ומתחתיו טיימר חופשי (stopwatch) עם "התחילו" כדי לחזור לאפליקציה ולהתחיל את הזמן יחד.

- video: כפתור "בחרו סצנה" (פותח YouTube בטאב חדש) + "סיימנו".

- guess: טקסט המשימה, ואחרי "סיימנו" שאלה: "מי ניחש נכון?" – שני כפתורים עם שמות בני הזוג. הנבחר מקבל הודעה "[שם] בוחר/ת את הקטגוריה הבאה" וחוזרים לבחירה.



### 5. מסך סיום

"סיימתם את כל הקלפים. לילה טוב 🌙" + כפתור "ערב חדש".
```
