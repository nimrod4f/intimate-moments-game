# תוכנית יישום — משחק מקדים

## מה ייבנה
- אפליקציית מובייל מלאה בעברית וב־RTL, ללא הרשמה וללא שרת.
- מסך פתיחה עם אישור גיל, תהליך בניית אווירה ומסירת הטלפון בין בני הזוג.
- תפריט משחקים ומשחק קלפים מלא עם 18 הקלפים שסופקו, הגרלה ללא חזרות והחלפה אחת בכל קטגוריה.
- קלפי טקסט, טיימר, שיר, וידאו וניחוש, כולל צליל ורטט בסיום טיימר.
- מסך סיום ואפשרות להתחיל ערב חדש.

## מראה וחוויה
- עיצוב כהה וחמים לפי הצבעים המדויקים שנמסרו, פונט Heebo, כפתורים גדולים ואנימציות רכות.
- התאמה למסך טלפון אחד שמועבר בין שני בני הזוג.
- שם האפליקציה הגלוי יהיה "משחק מקדים", בעוד שם הטאב והאייקון במסך הבית יהיו "Evening".

## שמירה והתקנה
- שמירת האווירה, הקלפים שנפתחו וזכאות ההחלפה בדפדפן המקומי בלבד.
- קובץ התקנה למסך הבית ואייקוני סהר דיסקרטיים, ללא מצב אופליין.

## בדיקה
- בדיקת הזרימה במסך מובייל, לרבות פתיחת קלף והפעלת הטיימר.
- צילום מסך של בחירת הקלפים ושל הטיימר לצורך סבב התיקונים.

## פרטים טכניים
- React עם TanStack Start ו־Tailwind CSS v4.
- Motion לאנימציות מעבר, ערבוב והיפוך קלף.
- מצב גלובלי ב־Context המסונכרן ל־localStorage לאחר טעינת הדפדפן.
